# Design system and visual baseline

The current visual language is preserved. Core tokens live in `src/style.css`: warm off-white background, deep green ink, teal accent, gold secondary signal, semantic surface/line/muted variables and a dark theme token override. Typography uses Tajawal for Arabic and DM Sans/Manrope for Latin display hierarchy.

## Reusable patterns

Header, sidebar, mobile bottom navigation, brand, buttons, text links, page hero, app heading, persona card, directory card, empty state, loading skeleton, toast, form fields, profile card, event detail, resource card, experience card and admin rows.

## Persona accents

LaunchPad terracotta; FreelanceSpace blue; HR Connect violet/neutral; StudentZone green. Accent use is bounded to card edges/backgrounds while typography and layout remain shared.

## Baseline changes in this iteration

- Removed the preview banner and preview-only wording.
- Kept header height, spacing, page heroes, dashboard shell and all existing palettes.
- Added Programs, Rooms and Partners using the existing page hero, card border, typography and responsive rules.
- Populated empty directories without fabricated success metrics or partner claims.
