# Coding-agent prompt set

Each prompt must start by reading `documentation/README.md`, `15-Traceability/REQUIREMENTS_MATRIX.csv`, the actual router, models, routes and tests. Never include secrets. Preserve the current design and E-USAM isolation.

## Master orchestrator

Reconcile requirements to code evidence, assign bounded changes by domain, require tests and update traceability. Do not promote a status without file and test evidence.

## Historical/source audit

Inspect only available repositories and artifacts. Record commit, branch, date and access gaps. Classify statements as decided, reported, verified, proposed, blocked or unknown.

## Frontend implementation

Implement the next missing routes from the page catalog using existing tokens/components. Wire real API states, accessible loading/error/empty/success flows, AR/EN and RTL. Reject dead controls.

## Backend/API and data

Add versioned migrations and typed contracts before new models. Enforce owner/role/tenant checks, idempotency, transaction boundaries and negative tests. Never point tests at production.

## Persona workflows

Implement structured LaunchPad, FreelanceSpace, HR Connect and StudentZone entities without duplicating Jobs or Education data. Validate consent at every handoff.

## Social, rooms and events

Implement groups/private visibility, room application/review/check-in/feedback and organizer workflow. Test capacity races, duplicate use, cancellation and permission filtering.

## AI/NomadAI

Build a policy-aware gateway, tool allowlist, tenant-filtered retrieval, citations, budget limits and evaluation suite. Keep all consequential actions behind explicit human approval.

## Partner/offers/admin

Implement organization teams, partner states, issuer verification, offer eligibility/redemption and scoped analytics. Add audit records and server authorization.

## Security/UX/QA/release

Run dependency, auth, privacy, RTL, accessibility, browser E2E, performance, backup and rollback checks. Produce evidence logs and a release recommendation with blocking issues.

## Final independent audit

Re-enumerate routes, APIs, models, migrations, tests and ZIP contents without relying on the implementation report. Recompute hashes, check internal links and downgrade any unsupported status.
