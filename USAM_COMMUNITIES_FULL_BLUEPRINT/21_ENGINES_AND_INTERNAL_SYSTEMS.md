# Engines and Internal Systems

**Purpose:** Capability classification  
**Applies to:** USAM Communities React/Node.js/EC2 package  
**Sources:** audited source at commit lineage `03ea43c...`, Universal Blueprint v1.1, supplied master prompt, official sources ledger  
**Status:** CURRENT + TARGET

Required now: identity/sessions, RBAC, communities/feed, events, moderation, billing/entitlements, admin, audit, search and notifications. Valuable later: queue/workflow, feature flags, advanced analytics, realtime, SSO and multi-tenant organization controls. Not suitable for current MVP: microservices, self-hosted large language model on the current EC2, crypto payment or complex marketplace settlement. Dedicated specs live under `engine_specs/`.
