# Personas, Journeys and Value Proposition

**Purpose:** Who receives value and how  
**Applies to:** USAM Communities React/Node.js/EC2 package  
**Sources:** audited source at commit lineage `03ea43c...`, Universal Blueprint v1.1, supplied master prompt, official sources ledger  
**Status:** CURRENT + TARGET

| Persona | First value | Repeat value | Paid trigger |
|---|---|---|---|
| Founder | useful community conversation | room/program, mentor, event | Plus/Pro for curated access |
| Freelancer | profile and case-study feedback | collaboration, perks, visibility | Plus/Pro |
| HR/employer | talent context and organization presence | events, approved opportunities | Organization |
| Student | learning community and resources | challenges, projects, rooms | Free first; Plus when value is proven |
| Operator/admin | trustworthy published inventory | review queues and audit trail | internal role |

Journey: Discovery → local/EC2 onboarding → join a community → first post/resource/event → repeat through programs and relationships → choose plan → support/cancel → data request/account exit. Payment failure never grants entitlement.
