# AI, NomadAI and Evaluation

**Purpose:** Value gate and safety requirements  
**Applies to:** USAM Communities React/Node.js/EC2 package  
**Sources:** audited source at commit lineage `03ea43c...`, Universal Blueprint v1.1, supplied master prompt, official sources ledger  
**Status:** BLOCKED / TARGET

NomadAI is not implemented. Candidate value: onboarding guidance, relevant resource discovery and community summarization with citations. Non-AI alternative: deterministic recommendations from persona, memberships and saved content. Before pilot: provider approval, data-processing terms, access-aware retrieval, prompt-injection tests, redaction, quotas, cost ceiling, human escalation, evaluation set and clear provenance. No AI action may post, message, approve, charge or disclose private member data without explicit human confirmation.
