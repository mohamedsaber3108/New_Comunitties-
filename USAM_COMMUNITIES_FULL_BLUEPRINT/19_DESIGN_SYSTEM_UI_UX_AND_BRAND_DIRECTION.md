# Design System, UI/UX and Brand

**Purpose:** Preserved visual language and tokens  
**Applies to:** USAM Communities React/Node.js/EC2 package  
**Sources:** audited source at commit lineage `03ea43c...`, Universal Blueprint v1.1, supplied master prompt, official sources ledger  
**Status:** CURRENT + TARGET

Preserve deep green `#092522`, teal `#16736d`, warm gold `#d9ad47`, off-white `#f7f8f6`, editorial cards and USAM wordmark. Fonts: Tajawal Arabic; DM Sans/Manrope Latin. Current variables define surface, ink, muted, line, soft, accent and shadows for light/dark. Cards use clear borders and restrained radii; pricing emphasizes one Plus plan without false urgency. Required states: default/hover/focus/disabled/loading/error/empty/success/pending. Never use color alone for billing state.
